# House Price Prediction

A simple Machine Learning project that predicts house prices using Linear Regression.

## About the Project

This project uses house-related features such as area, number of bedrooms, and other available information to predict house prices.

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning Model

* Linear Regression

## Project Workflow

1. Load the dataset
2. Perform data cleaning
3. Explore the data using visualization
4. Split the dataset into training and testing sets
5. Train the Linear Regression model
6. Predict house prices
7. Evaluate the model using MAE, MSE, and RMSE

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run the cells to train the model and predict house prices.
